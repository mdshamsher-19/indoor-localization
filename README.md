# Indoor Localization using Machine Learning

## Overview
Machine Learning Based Indoor Human Localization System using Bluetooth RSSI Signals.

## Technologies Used
- ESP32
- Bluetooth Low Energy (BLE)
- Python
- K-Nearest Neighbors (KNN)
- Firebase

## Description
This project uses Bluetooth RSSI signals collected using ESP32 devices
to estimate the indoor location of a person. RSSI data is collected,
processed, and used with a KNN-based machine learning approach for
location prediction.
